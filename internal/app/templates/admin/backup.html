지금 내려받기

{{/* A-604 (FR-713). 받는 것은 zip 하나 — DB 덤프(pg_dump custom 형식)와 업로드 폴더. */}}

DB 덤프(ondolith.dump)와 업로드 파일(uploads/)을 zip 하나로 내려받습니다. 회원 정보와 비밀번호 해시가 들어 있으니 안전한 곳에 보관하세요. 로그인 세션은 들어 있지 않습니다.

설정 파일(ondolith.json)과 사용자 테마는 들어 있지 않습니다. 결제·메일 키는 설정 파일의 secret_key 로 봉인돼 있어, 설정 파일 없이 복원하면 관리자 화면에서 키를 다시 넣어야 합니다.

복원: 빈 DB 를 새로 만들고 pg_restore --no-owner --exit-on-error -d <DB> ondolith.dump, uploads/ 는 업로드 폴더에 그대로 풉니다.

자동 백업

{{/* FR-715. 서버가 매일 정한 시각에 백업 폴더(backup_dir)에 같은 zip 을 만들고 오래된 것을 지운다. */}}
{{/* FR-722. 파일 저장소가 S3 면 백업도 그 버킷의 backups/ 로 간다 — 서버를 잃어도 남는다. */}} {{if .ToBucket}}

파일 저장소가 S3 라 자동 백업은 그 버킷의 backups/ 에 올라가고 이 서버에는 남지 않습니다 — 서버를 잃어도 백업이 남습니다. 버킷의 백업은 앱이 지우지 않습니다. 버킷에 수명 주기 규칙을 걸지 않으면 모두 쌓이고, 걸면 그 날수가 보관 기간입니다(backups/ 접두사에만). 「서버에 남길 개수」는 버킷에 올리지 못해 이 서버에 남긴 백업에만 적용되고, 그런 날은 작업 로그에 적습니다.

{{else}}

백업 하나가 DB 와 업로드 폴더 전체라 보관 개수만큼 디스크를 씁니다. 백업은 이 서버의 디스크에 있으므로, 서버가 망가지면 함께 사라집니다 — 서버 스냅샷(Lightsail 자동 스냅샷)도 켜 두세요. 파일 저장소를 S3 로 쓰면 자동 백업도 그 버킷으로 갑니다.

{{end}}
