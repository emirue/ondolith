# D73. 토스페이먼츠 실측 절차 (W3-34)

Phase 3의 완료 기준 중 **실제 PG를 상대로 확인해야 하는 것**들의 절차다. 테스트 키만
있으면 여기 적힌 것을 그대로 실행할 수 있다.

관련: [D50 커머스](50-commerce.md) · [D13 A-209 결제 설정](13-screens-admin.md)

---

## 0. 테스트 키 넣기

토스페이먼츠 개발자센터에서 **테스트 키**를 발급받는다 (`test_ck_…` / `test_sk_…`).

관리자 화면 `/admin/settings/payment`(A-209)에 넣는다. 시크릿 키는 저장 후 **어떤
화면에도 다시 표시되지 않는다** — 넣을 때 한 번만 보인다.

> **라이브 키로 이 절차를 돌리지 않는다.** 아래 자동 검사는 `test_` 접두사를 확인하고,
> 아니면 실행을 거부한다.

---

## 1. 자동으로 확인되는 것

```bash
ONDOLITH_TOSS_TEST_SECRET=test_sk_... make test-toss
```

| 확인 | 무엇을 증명하나 |
|---|---|
| 없는 `paymentKey` 조회가 **구조화된 4xx**로 거부된다 | 어댑터가 API와 말이 통한다. 전송·파싱 단계에서 끝나지 않는다 |
| 그 거부가 **401이 아니다** | Basic 인증 인코딩이 맞다 — `test_sk_x:`의 **콜론까지** 포함해서 |
| 없는 키로 승인 시도가 거부된다 | 승인 경로도 같은 자격증명으로 통한다 |
| 오류 문자열·어댑터 출력에 **시크릿이 없다** | 오류는 로그와 화면으로 흘러간다 |

`make check`·`make test-integration`에는 넣지 않는다. 네트워크와 토스 계정이 필요하고,
없는 환경에서 SKIP이 생기면 이 저장소의 게이트가 그것을 거부한다
([D82](82-execution-loop.md)). 빌드 태그 뒤에 두어 **태그 없이는 컴파일조차 되지 않게**
했다 — 조건부 SKIP이 아니라 아예 없는 코드다.

---

## 2. 브라우저가 있어야 하는 것

**승인 한 건이 끝까지 가는 것**(W3-34 ①)은 자동화할 수 없다. 토스의 승인 API는 결제창이
발급한 `paymentKey`를 요구하고, 그 키는 사람이 결제창에서 인증해야 나온다.

1. `shop` 모드로 설정하고 상품을 하나 만든다
2. 장바구니 → 주문서 → 결제 (테스트 카드로 인증)
3. 확인할 것:

| 확인 | 어디서 |
|---|---|
| 주문이 `결제완료`가 된다 | `/admin/orders` |
| `payments`에 승인 행이 남고 금액이 주문 금액과 같다 | A-508 결제 대사 |
| 대사 화면에 차이가 없다 | `/admin/reconcile` |
| **가상계좌라면** 입금 웹훅이 A-603에 남는다 | `/admin/webhooks` |

웹훅을 받으려면 인스턴스가 **외부에서 접근 가능해야 한다.** 로컬 개발기에서는 오지 않는다.

---

## 3. 이미 자동으로 확인되는 것 (실측 불필요)

W3-34의 나머지 항목은 **우리 쪽 규칙**이고, 실제 PG 없이 `make test-integration`이
매번 확인한다. 토스가 있어야 확인되는 것이 아니다:

| 항목 | 확인하는 검사 |
|---|---|
| ② 금액 조작 요청이 승인되지 않는다 | `TestAmountMismatchNeverReachesTheGateway` — **승인 API를 부르기 전에** 거부한다 |
| ③ 같은 주문 이중 승인이 DB 제약으로 막힌다 | `payments_order_approved_idx` 부분 유니크. 애플리케이션 검사를 우회해 직접 넣어도 실패한다 |
| ④ 웹훅 재전송에 결과가 같다 | `TestWebhookIsIdempotentOnResend` — `(pg, event_id)` 유니크가 멱등의 근거다 |
| ⑤ 부분환불 누적이 결제액을 넘지 않는다 | `CHECK (환불누적액 <= 승인금액)` + 동시 부분환불 25회차 검사 |

**이것들을 PG에 의존해 확인하지 않는 것이 설계다.** 토스가 거부해 주기를 기대하는 규칙은
토스가 정책을 바꾸면 사라진다.
