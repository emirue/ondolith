# D18. 미결 대장

**아직 정하지 않은 것을 여기 한 곳에만 적는다.**

전에는 문서마다 `## 아직 정하지 않은 것` 표를 뒀는데, 결정을 내려도 표를 안 지워
**결정된 항목이 미결로 남고**(6건), 같은 항목이 **최대 4곳에 중복**됐다. 원본 68줄에서
중복·해결분을 걷어내니 실제 미결은 37건이었다.

## 규칙

| # | 규칙 |
|---|---|
| 1 | 미결 표는 **이 문서에만** 둔다. 다른 문서에 `## 아직 정하지 않은 것` 표가 있으면 `make check` 실패 |
| 2 | 결정하면 **행을 지우고** 결정 내용을 해당 주제 문서에 쓴다. 대장에 `결정됨`으로 남기지 않는다 — 대장이 커지면 아무도 안 읽는다 |
| 3 | 화면 상세의 한 줄짜리 `**미결**:` 메모는 그대로 둔다. 그건 목록이 아니라 문맥이다. **다만 반드시 `OPEN-##`을 인용한다** — 인용이 없거나 대장에 없는 항목을 가리키면 `make check` 실패. 이 연결이 없어 결정된 항목이 화면 상세에 6건 남았다 ([M11](../.ai/MISTAKES.md)) |
| 4 | `결정 시점`은 Phase이거나 `미정`이다. `미정`은 **요구사항이 없어서 안 정한 것**이지 미룬 것이 아니다 |

## 최근 닫은 것 (2026-08-02) — Phase 1 착수 조건

**규칙 2대로 대장에서는 지웠다.** 여기 남기는 것은 목록이 아니라 **왜 그렇게 정했는지**다.
같은 질문이 다시 올라오면 이 표를 먼저 본다.

| 닫은 항목 | 결정 | 근거 | 반영 |
|---|---|---|---|
| 이메일 인증 | **설정으로 켜고 끈다(기본 켬).** 가입 승인제는 범위 밖 | 인증 없이 열면 스팸 계정이 게시판을 채운다. 다만 사내망처럼 메일 발송이 곤란한 설치처가 있다. 승인제는 관리자 워크플로가 통째로 붙어 별도 설계 | FR-214, P-112·P-113, `email_verification_tokens`, A-201 설정 |
| 소셜↔로컬 같은 이메일 | **어떤 경우에도 자동 연결하지 않는다** | 자동 연결을 허용하면 프로바이더 계정 하나를 뚫는 것이 곧 우리 계정을 뚫는 것이 된다. 연결을 정하는 주체는 계정 주인이어야 한다 | [D12](12-screens-public.md) P-107 |
| 메일 발송 실패 | **큐를 만들지 않는다.** 고루틴 비동기 + 3회 지수 백오프 + 작업 로그 | 큐 테이블을 두면 관리 화면이 또 필요하고 NFR-103(별도 워커 없음)과 어긋난다. 재설정·인증 메일은 재요청이 되므로 유실이 막다른 길이 아니다 | [D13](13-screens-admin.md) A-205 |
| rate limit | **메모리 토큰 버킷.** 임계값 6종 명시 | 수평 확장이 비목표라 DB에 넣을 이유가 없다. 재시작 초기화는 받아들인다 — 지속성보다 판정 속도가 중요하다 | [D15](15-access-control.md) 4.3-2 |
| 관리자 세션 수명 | **일반과 동일(12시간). 대신 파괴적 작업에 재인증** | 세션을 짧게 하면 하루에 여러 번 로그인하게 되고 그건 피싱 훈련이 된다. 위험한 행위 시점에 묻는 것이 효과가 크다 | [D15](15-access-control.md) 5.3-1 |
| 권한 캐싱 범위 | **요청 context에만.** 세션·프로세스 캐시 없음 | 세션 캐시는 권한 회수가 안 먹는다. 프로세스 캐시는 무효화가 필요해지고 무효화는 버그의 원천이다. 얻는 것은 조인 하나 | [D15](15-access-control.md) 4.3-1 |
| 공개 메뉴 권한 숨김 | **숨긴다** | 권한이 요청당 1회 로드되므로 항목마다 판정해도 추가 쿼리가 없다. 숨기는 이유는 성능이 아니라 비공개 게시판의 존재가 메뉴로 새지 않게 하려는 것이고, 404 정책과 일관된다 | [D13](13-screens-admin.md) A-204 |
| `theme.json` `requires` | **major.minor.patch 숫자 비교.** 미달이면 활성화 거부, 개발 빌드는 경고만 | 프리릴리즈 규칙까지 갈 정밀도가 테마 호환성 판단에 필요하지 않다. 활성화한 뒤 깨지는 것보다 거부가 낫다 | [D17](17-theme-contract.md) |
| `asset` 캐시 무효화 | **파일 내용 해시** | 테마 버전을 쓰면 **버전을 안 올리고 파일만 고치는** 가장 흔한 작업에서 캐시가 안 깨진다 | [D17](17-theme-contract.md) |
