# D10. 기획 문서 — 요구사항 명세

이 문서가 "무엇을 만드는가"의 단일 출처다. 코드·커밋·이슈는 여기의 ID를 인용한다.

**읽는 법**

- `FR-###` 기능 요구사항 / `NFR-###` 비기능 요구사항
- **필수** = 해당 Phase 완료 조건. **선택** = 여유가 있으면.
- 각 항목의 "완료 기준"은 검증 가능하게 쓴다. "잘 동작한다"는 완료 기준이 아니다.

| 대역 | 영역 | 주 Phase |
|---|---|---|
| FR-1xx | 설치 | 0 |
| FR-2xx | 인증·세션·권한 | 1 |
| FR-3xx | 테마 | 1 |
| FR-4xx | 페이지 | 1 |
| FR-5xx | 게시판 | 2 |
| FR-6xx | 커머스·결제 | 3 |
| FR-7xx | 관리자 | 1~3 |
| NFR-1xx | 성능·자원 | 전체 |
| NFR-2xx | 보안 | 전체 |
| NFR-3xx | 배포·패치 | 0, 4 |
| NFR-4xx | 확장성·유지보수 | 전체 |

## FR-1xx 설치

> 그누보드와 같은 경험이 목표다. 터미널을 열지 않고 브라우저에서 끝난다.
> 이 구조는 **프로젝트 초기에** 잡아야 한다. 나중에 얹으면 라우팅 전체를 뜯게 된다.

| ID | 요구사항 | 우선 | Phase | 완료 기준 |
|---|---|---|---|---|
| FR-101 | 미설치 상태로 기동하면 모든 요청이 `/install`로 유도된다 | 필수 | 0 | 설정 파일이 없을 때 `/`, `/admin`, `/아무거나` → `303 → /install` |
| FR-102 | 설치 폼에서 DB 접속정보·관리자 계정·사이트 이름을 받는다 | 필수 | 0 | 폼 제출 한 번으로 설치가 끝난다 |
| FR-103 | 마이그레이션은 바이너리에 내장되어 자동 실행된다 | 필수 | 0 | 별도 CLI 실행 단계가 없다 (`embed.FS` + goose) |
| FR-104 | 첫 관리자 계정을 생성한다 | 필수 | 0 | 비밀번호는 bcrypt 해시로만 저장된다 |
| FR-105 | 설정 파일을 기록하고 설치 완료로 표시한다 | 필수 | 0 | 파일 권한 `0600`. DB 비밀번호가 들어 있다 |
| FR-106 | 설치 후 재시작 없이 운영 모드로 전환된다 | 필수 | 0 | 설치 완료 직후 `/`가 사이트를 반환한다 |
| FR-107 | 설치 실패 시 원인을 사용자에게 그대로 보여준다 | 필수 | 0 | DB 접속 실패·권한 부족 메시지가 화면에 나온다 |
| FR-108 | 이미 사용 중인 DB에 덮어쓰지 않는다 | 필수 | 0 | 같은 이메일의 계정이 있으면 거부하고 안내한다 |
| FR-109 | 설치 마법사가 콘솔 토큰을 요구하지 않는다 | 필수 | 0 | [DEC-3.3](../.ai/DECISIONS.md) — PocketBase 방식 배제 근거 |
| FR-110 | 설정 파일이 깨졌을 때 설치 모드로 되돌아가지 않는다 | 필수 | 0 | 파싱 실패 시 기동 중단. 지나가는 사람이 사이트를 재점유할 수 없다 |

**핵심 설계 원칙:** 설치 전과 설치 후는 **완전히 다른 라우트 트리**를 갖는다. 하나의 라우터에
조건 분기를 넣지 말고, 기동 시점에 어느 트리를 등록할지 결정한다. ([D20](20-architecture.md))

## FR-3xx 테마

> 테마 시스템은 이 제품의 존재 이유다. 여기서 타협하면 만들 이유가 없다. ([D40](40-theme.md))

| ID | 요구사항 | 우선 | Phase | 완료 기준 |
|---|---|---|---|---|
| FR-301 | 기본 테마는 바이너리에 내장된다 | 필수 | 1 | 파일 하나만 배포해도 사이트가 뜬다 |
| FR-302 | 디스크의 사용자 테마가 내장 테마를 오버라이드한다 | 필수 | 1 | 같은 이름의 템플릿이 디스크에 있으면 그쪽이 쓰인다 |
| FR-303 | 테마 교체에 재컴파일·재시작이 필요 없다 | 필수 | 1 | 관리자에서 테마를 바꾸면 다음 요청부터 적용 |
| FR-304 | 코어가 템플릿 함수맵을 제공한다 | 필수 | 1 | URL 생성, 페이지네이션, 날짜·숫자 포맷, 에스케이프 헬퍼 |
| FR-305 | 테마에 비즈니스 로직을 넣을 수 없다 | 필수 | 1 | 템플릿은 준비된 데이터만 받는다. DB 접근 함수를 노출하지 않는다 |
| FR-306 | 개발 모드에서 템플릿 캐시를 끈다 | 필수 | 1 | 파일을 고치면 새로고침만으로 반영 |
| FR-307 | 테마 업로드(zip) | 선택 | 2 | 압축 해제 경로 검증 필수 (Zip Slip) → [D60](60-security.md) |
| FR-308 | 테마가 요구하는 템플릿 목록이 문서화된다 | 필수 | 1 | 없는 템플릿은 내장 테마로 폴백 |
| FR-309 | 테마 정적 자산(CSS·JS·이미지)을 서빙한다 | 필수 | 1 | 내장 테마는 `embed.FS`에서, 디스크 테마는 파일에서. 테마 디렉터리 밖 파일에 접근할 수 없다 |

| FR-622 | 재고 실사 | 필수 | 3 | 스캔한 조합의 **실측 수량**을 입력하면 장부와의 차이를 계산해 조정하고, 조정 전후 수량과 차이를 작업 로그에 남긴다 |
| FR-623 | 출고 피킹 대조 | 필수 | 3 | 주문 건의 품목을 스캔으로 대조한다. **주문에 없는 조합·수량 초과는 거부**하고, 전 품목이 맞아야 대조 완료로 기록된다. 주문 상태는 바꾸지 않는다 — 전이는 A-510이 일으킨다 |
| FR-624 | 스캔 재고 조회 | 필수 | 3 | 스캔하면 그 조합의 현재 재고·상품·옵션을 보여준다. **어떤 상태도 바꾸지 않는다** |
| FR-625 | 품목 단위 부분 취소·환불 | 필수 | 3 | 구매자·관리자가 **품목과 수량을 골라** 취소·환불한다. 금액은 서버가 `order_items` 스냅샷에서 계산하며 **요청 금액을 받지 않는다**. 같은 품목을 소진 수량 이상 환불할 수 없다 (`settled_quantity` DB 제약) |
| FR-626 | 주문 할인 | 필수 | 3 | 주문 단위 할인액을 받는다. 할인은 **주문 생성 시 품목에 배분되어 스냅샷으로 저장**되고, 부분 취소는 그 스냅샷으로 계산한다 — 배분 합계는 언제나 주문 할인액과 정확히 같다 (반올림 누락·초과 없음) |

**절대 금지:** 카드번호·유효기간·CVC를 DB에 저장하지 않는다 ([DEC-3.7](../.ai/DECISIONS.md)).
정기결제가 필요하면 빌링키만 사용한다.

## FR-7xx 관리자

> 관리자 화면은 **직접 구현한다.** CRUD 자동 생성기에 의존하지 않는다 ([DEC-3.10](../.ai/DECISIONS.md)).
> 게시판 설정, 테마 관리, 상품 옵션 편집기는 자동 생성으로 나오지 않기 때문이다.

| ID | 요구사항 | 우선 | Phase | 완료 기준 |
|---|---|---|---|---|
| FR-701 | 관리자 셸 (레이아웃·메뉴·권한별 노출) | 필수 | 1 | 권한 없는 메뉴는 렌더링되지 않는다 |
| FR-702 | 대시보드 | 선택 | 1 | 최근 글·주문 요약 |
| FR-703 | 사이트 설정 | 필수 | 1 | 사이트 이름, 기본 메타, 테마 선택 |
| FR-704 | 사용자·역할 관리 | 필수 | 1 | 마지막 관리자의 회수·삭제·비활성이 거부된다. 동시 요청 두 건 중 하나만 성공한다 ([D15](15-access-control.md) 5.2) |
| FR-705 | 게시판 설정 UI | 필수 | 2 | FR-501, FR-502의 화면 |
| FR-706 | 상품·주문 관리 UI | 필수 | 3 | 상품 등록부터 주문 조회·상태 변경까지 관리자 화면만으로 끝난다 (A-501 ~ A-508) |
| FR-707 | 작업 로그 (operation log) | 선택 | 2 | 누가 무엇을 언제 바꿨는가 |
| FR-708 | 메일 발송 설정 | 필수 | 1 | 관리자가 SMTP를 설정하면 FR-207 재설정 메일이 발송된다. 비밀번호는 평문으로 화면에 다시 표시하지 않는다 |
| FR-709 | 소셜 로그인 프로바이더 설정 | 선택 | 1 | 관리자가 프로바이더 키를 넣으면 P-106이 활성화된다. 시크릿은 재표시하지 않는다 |
| FR-710 | **사이트 유형 설정 (일반 사이트 / 쇼핑몰)** | 필수 | 1 | 설치 시 고르고 나중에 바꿀 수 있다. 일반 사이트로 두면 커머스 화면의 라우트가 **등록되지 않는다** — 숨기는 것이 아니라 존재하지 않는다 |
| FR-711 | 사업자 정보 설정 | 필수 | 3 | 상호·대표자·사업자번호·통신판매업신고번호·주소·연락처를 설정하면 테마가 푸터에 렌더링한다. `shop` 모드에서 미입력이면 관리자에게 경고를 띄운다 |
