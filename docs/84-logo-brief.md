# D84. 로고 제작 요청서

외부 도구(ChatGPT·이미지 생성 모델·디자이너)에 그대로 붙여 넣어 쓰는 요청서다.
현재 리포에 들어 있는 마크는 **자리를 비워 두지 않으려고 임시로 그린 것**이고,
이 문서로 받은 결과로 교체하는 것을 전제로 한다.

교체 위치는 두 곳이다.

| 파일 | 쓰이는 곳 |
|---|---|
| `internal/app/templates/admin/logo.svg` | 관리자 헤더 (A-102) |
| `internal/install/templates/install.html` 내 인라인 `<svg>` | 설치 마법사 (P-001) |

**프론트 화면에는 넣지 않는다.** 그쪽에 서는 것은 사이트 운영자의 브랜드이지
Ondolith 가 아니다.

## 붙여 넣을 요청문

```
로고를 만들어 주세요. SVG 코드로 주시고, 설명은 짧게 부탁합니다.

## 제품

이름: Ondolith (온돌리스)
무엇인가: 실행 파일 하나로 도는 웹사이트 제작 도구입니다. 서버에 파일 하나를
올리고 브라우저에서 설치를 마치면 홈페이지·게시판·쇼핑몰이 됩니다.
설치가 어렵지 않고, 켜 두면 알아서 도는 것이 이 제품의 성격입니다.

이름의 뜻: 한국의 전통 난방 '온돌'과 돌을 뜻하는 그리스어 어근 'lith'를
합친 말입니다. 온돌은 아궁이의 열이 구들장(바닥 돌판)을 데우고, 그 돌이
불을 끈 뒤에도 오래 온기를 머금는 구조입니다. "한 번 잘 깔아 두면 오래
따뜻하다"가 제품이 말하려는 성격입니다.

## 만들어 주셨으면 하는 것

1. 심볼 마크 (아이콘 단독)
2. 심볼 + 영문 'Ondolith' 워드마크 가로 조합

## 형식 요건 (중요)

- **SVG 코드로 주세요.** PNG·JPG는 쓰지 않습니다.
- viewBox="0 0 32 32" 정사각 기준으로 그려 주세요.
- 색은 fill="currentColor" / stroke="currentColor"만 쓰고
  **하드코딩된 색값(#RRGGBB)을 넣지 마세요.** 밝은 배경과 어두운 배경
  양쪽에서 같은 파일을 그대로 씁니다.
- **단색 한 가지로만** 그려 주세요. 그라디언트·다중 색상·투명도 단계를
  쓰지 마세요.
- **16×16 픽셀로 줄여도 형태가 읽혀야 합니다.** 헤더에서 그 크기로 쓰입니다.
  획 두께는 32 기준 2.5 이상으로 잡아 주세요.
- 텍스트를 <text>로 넣지 말고, 워드마크가 필요하면 패스로 변환해 주세요.
- <filter>, <image>, 외부 폰트 참조를 쓰지 마세요.

## 분위기

- 부드럽고 현대적인 쪽. 둥근 모서리와 여유 있는 형태.
- 딱딱하고 각진 기업 로고 느낌은 피해 주세요.
- 한국적 소재를 쓰되 민속적·전통 문양처럼 보이지는 않게, 절제된
  기하학적 형태로 부탁합니다.
- 제품의 UI 강조색은 짙은 초록(#1f7a63)이고 배경은 따뜻한 회백색
  (#f7f5f2)입니다. 그 위에 올렸을 때 어울리는 형태면 좋겠습니다.

## 방향 제안 (이 중 하나여도 되고, 더 나은 안이 있으면 그것으로)

A. 구들장 위로 올라오는 온기 — 아래에 두꺼운 가로 판, 그 위로 부드럽게
   올라가는 곡선 몇 줄기. '뜨거운 표면' 픽토그램과 비슷한 구조.
B. 구들 단면 — 돌판과 그 아래로 열이 지나가는 통로(고래)를 옆에서 본 형태.
C. 'O' 모노그램 — 원 또는 둥근 사각형 안에 온기를 뜻하는 요소.
```

## 받은 뒤 확인할 것

요청문에 적힌 형식 요건은 **받은 SVG 를 열어 직접 확인한다.** 생성 모델은
`fill="#1f7a63"` 처럼 색을 박아 넣거나 `<filter>` 를 끼워 넣는 일이 잦다.

| 확인 | 방법 |
|---|---|
| 하드코딩된 색이 없다 | `grep -E '#[0-9a-fA-F]{3,6}' logo.svg` 가 비어 있다 |
| 외부 참조가 없다 | `grep -E '<image|<filter|href=' logo.svg` 가 비어 있다 |
| 16px 에서 읽힌다 | 브라우저에서 `width:16px` 로 놓고 눈으로 본다 |
| 어두운 배경에서 보인다 | 관리자 화면을 다크 모드로 열어 본다 |

교체는 파일 두 곳을 같은 도형으로 맞추는 것으로 끝난다. 설치 트리는 운영
트리의 자원을 쓰지 않으므로(CLAUDE.md 3번) 인라인 사본이 따로 있다 — **한
쪽만 바꾸면 설치 화면과 관리자 화면의 로고가 달라진다.**
