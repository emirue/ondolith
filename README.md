# Ondolith

**온돌(溫突) + monolith** — 집 바닥 전체에 깔려 집을 데우는 기반 설비처럼, 사이트 전체를
떠받치는 단일 바이너리.

Go로 작성하는 오픈소스 CMS + 커머스 플랫폼. 단일 바이너리로 배포되며, 브라우저에서
설치가 끝나고, 테마를 재컴파일 없이 교체할 수 있고, 한국형 쇼핑몰 결제를 지원한다.

> **상태: 개발 초기 (Phase 0).** 아직 동작하는 릴리즈가 없다. 프로덕션에 쓰지 말 것.

## 목표

- AWS Lightsail 저사양 인스턴스 단일 서버에서 동작
- 터미널 작업 없이 브라우저 안에서 설치 완결
- 런타임 테마 교체 (재컴파일 없음)
- 관리자 화면에서 게시판/페이지를 생성·설정
- 한국형 커머스 (토스페이먼츠 우선)
- 프론트·관리자·API가 하나의 바이너리, 하나의 서버

## 비목표

수평 확장, 멀티 노드, 헤드리스/API 우선 아키텍처, 서드파티 플러그인 마켓,
다국어(한국어 우선 — i18n 구조만 열어둔다).

## 스택

| 영역 | 선택 |
|---|---|
| 언어 | Go 1.25+ |
| 라우터 | `net/http.ServeMux` (표준 라이브러리) |
| 테마 렌더링 | `html/template` (런타임 로딩) |
| CSRF | `net/http.CrossOriginProtection` (표준 라이브러리) |
| 세션 | `alexedwards/scs/v2` + `pgxstore` |
| DB | PostgreSQL (`jackc/pgx/v5`) |
| 마이그레이션 | `pressly/goose/v3` (`embed.FS` 내장) |
| 인터랙션 | htmx |

설계 결정과 **배제된 선택지**의 근거는 [`.ai/DECISIONS.md`](.ai/DECISIONS.md)에 있다.

## 로드맵

| Phase | 내용 | 상태 |
|---|---|---|
| 0 | 설치 마법사 스파이크 — 부팅 → 미설치 감지 → `/install` → 마이그레이션 → 운영 모드 | 진행 중 |
| 1 | 코어 — 인증/세션/권한, 관리자 셸, 테마 로더, 페이지 CRUD | |
| 2 | 게시판 — 정의/설정 UI, 커스텀 필드, 글/댓글, 첨부, 검색, SEO | |
| 3 | 커머스 — 상품/옵션/재고, 장바구니, 주문 상태머신, 토스페이먼츠 | |
| 4 | 배포 패키징 — 릴리즈 바이너리, 기본 테마, Lightsail 가이드 | |
